部署后的访问路径是：

```text
浏览器 --HTTPS--> Nginx（只接受指定域名）
                 |-- 静态页面
                 |-- /_g/ 与 /_gws/ --> 本机网关校验参数杂凑
                                      --> ISPmanager 门户 API（另一台服务器）
```

浏览器不直接访问管理端。接口地址写在项目根目录 `vite.config.js` 的 `API_PROXY_TARGET`，打包和安装会把它交给本机网关。分机部署时使用 `https://管理端域名:8443`，并配置与管理端相同的 `PORTAL_API_SECRET`。
